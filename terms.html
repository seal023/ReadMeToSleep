五、账号、会员归属与缴费凭证

1. 为什么需要在开通会员前登录

本 App 的会员权益与您的账号绑定，而不是与某一台手机绑定。因此开通会员前需要先登录（可使用「通过 Apple 登录」或「邮箱验证码登录」，二者任选其一）。

这样做是为了解决一个具体问题：缴费记录需要有明确归属，否则您换手机、重装 App 后将难以证明这笔费用是您支付的。

2. 您的缴费凭证在哪里查看

订阅成功后，您可以在 App 内 「家长中心 → 订阅管理」 页面的「订阅凭证」区域查看：

  • 订阅方案（月度 / 年度）；
  • 购买时使用的账号；
  • 购买日期与有效期截止日；
  • 是否处于自动续订状态；
  • App Store 交易号（用于向 Apple 核对或申诉）。

该页面还提供「在 App Store 查看官方购买记录」的入口。此外，Apple 会将正式收据邮件发送到您 Apple ID 绑定的邮箱，该邮件可作为报销或留存的正式凭据。

请理解：本 App 不接触、也不存储您的支付卡信息。扣款与收据由 Apple 出具，我方提供的是订阅状态与交易号的查询入口。

3. 更换设备或重装后如何找回会员

  1. 在新设备上安装本 App；
  2. 使用当初购买时的同一个账号登录（Apple 或邮箱）；
  3. 登录后 App 会自动向 App Store 查询并恢复您的会员，通常无需额外操作；
  4. 若未自动恢复，请进入「家长中心 → 订阅管理」，点击「恢复购买」。
关键前提：Apple 的自动续订订阅是记在 Apple ID 上的。因此新设备的 App Store 必须登录当初购买时那个 Apple ID，否则 Apple 不会把订阅交还给本 App，我们技术上也无法恢复。

4. 必须知晓的限制

  • 更换 Apple ID 无法恢复会员。这是 Apple 订阅机制的硬性限制，非本 App 可绕过。若您更换了 Apple ID，原订阅仍留在旧 Apple ID 下，本 App 内无法继续使用该权益。
  • 退出账号登录会失去会员状态。因为会员归属账号；重新登录后会自动恢复。
  • 注销账号不会退款。注销仅删除账号与关联数据，已产生的费用需按 Apple 的退款流程单独申请。
